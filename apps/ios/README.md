# RAFIKI Pin for iPhone and iPad

Native SwiftUI app with the same screens as the Android app (apps/android-native):
projects, map, pin location, site visit (photos, voice note), new site, Me, the Office,
route planning, the monthly report and monday.com sign-in. English and Kiswahili.

- Open `RafikiPin.xcodeproj` in Xcode 16 or later. Bundle ID `org.rafikioutreach.pin`, iOS 16+.
- Choose your team under Signing & Capabilities, then Product → Archive → Distribute (TestFlight / App Store).
- Demo mode for screenshots: launch with `-demo` (add `-screen office`, `-lang sw`, `-theme dark`…). It never talks to the real server.
